# Dziennik prac – 2026-02-26

## Zakres wdrożonych zmian

### 1. Logowanie centralne i wybór sekcji
- Strona główna `/` została uproszczona do samego logowania.
- Po poprawnym logowaniu użytkownik jest przekierowywany na `/choice`.
- Widok `/choice` prezentuje wyłącznie sekcje przypisane do konta (`admin`, `operator`, `generator`).
- Dodano wspólny przełącznik sekcji (lista rozwijana) w panelach `/admin`, `/operator`, `/genform`.

### 2. Uprawnienia sekcyjne użytkowników
- Rozszerzono model uprawnień o niezależne przypisanie sekcji do użytkownika.
- W sekcji `Użytkownicy` dodano pełną edycję konta (rola, telefon, sekcje).
- API logowania i autoryzacji zostało dostosowane do sekcji, nie tylko do roli.

### 3. Generator formularzy jako osobny flow
- Generator działa pod adresem `/genform` (oddzielnie od panelu `/admin`).
- Dodano:
  - logowanie z opcją „pokaż hasło”,
  - listę formularzy z akcjami `Wyświetl` i `Usuń`,
  - modal szczegółów formularza,
  - kolumnę `Utworzone przez`.
- Usunięto problem blokującego modala po otwarciu widoku.

### 4. Formularz publiczny – wersja etapowa
- Publiczny formularz `/formularz/{token}` został przebudowany do trybu etapowego:
  - krok 1: dane firmy,
  - krok 2: reprezentanci (z możliwością dodania wielu osób),
  - krok 3: podsumowanie i końcowe potwierdzenie.
- Dane są zapisywane dopiero po końcowym `Potwierdź i wyślij`.
- Payload formularza jest szyfrowany (Fernet, `ADMIN_SECRET_KEY`) i zapisywany jako `SUBMITTED`.

### 5. Powiadomienia po wysłaniu formularza
- Po zatwierdzeniu formularza system:
  - wysyła e-mail potwierdzający do klienta,
  - dodaje do kolejki SMS informację dla użytkownika, który wygenerował link (`origin=form_submission_completed`).
- Treści SMS z danymi wrażliwymi są maskowane w historii panelu.

### 6. Konfiguracja Firebird
- Utrzymano dwutrybową konfigurację Firebird:
  - `network` – baza sieciowa,
  - `local` – lokalna kopia robocza.
- W trybie lokalnym test połączenia wymusza host `127.0.0.1` i korzysta z `FB_LOCAL_COPY_PATH`.

### 7. Poprawka kopiowania linku w `/genform`
- Dla przycisku `Kopiuj link` dodano fallback:
  - priorytet: Clipboard API,
  - fallback: `document.execCommand("copy")`.
- Rozwiązanie eliminuje problem kopiowania w środowiskach bez `https` lub z ograniczonym Clipboard API.
