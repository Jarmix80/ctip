Konfiguracja Google Sheets (FLOW)

Arkusz używany do wpisywania rezerwacji GRENKE i numerów proform w module FLOW.

Źródło konfiguracji: .env.

Brak testu połączenia

Wyłączenie blokuje synchronizację arkusza niezależnie od wartości z pliku .env.

Możesz wkleić samo ID albo pełny URL Google Sheets. System zapisze wyłącznie ID skoroszytu.

Wymagane nagłówki FLOW: PRODUCENT, MODEL, INDEKS, SERIAL, STATUS, MS_ID_MAGAZYN_TABLE, MS_ID_MASZYNA, REZERWACJA GRENKE, FAKTURA PROFORMA GRENKE.
